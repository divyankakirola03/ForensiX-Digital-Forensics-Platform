# ForensiX - Digital Forensics Investigation Platform

## Overview

ForensiX is a Digital Forensics Investigation Platform developed using Python, Flask, and SQLite. It enables investigators to analyze digital evidence, generate forensic hashes, extract metadata, detect duplicate evidence, and generate PDF investigation reports.

## Features

* Evidence File Upload
* MD5 Hash Generation
* SHA256 Hash Generation
* Metadata Analysis
* EXIF Metadata Extraction
* SQLite Evidence Database
* Case ID Generation
* Duplicate Evidence Detection
* PDF Report Generation
* Dark Themed Investigation Dashboard

## Tech Stack

* Python
* Flask
* SQLite
* HTML
* CSS
* ReportLab
* Pillow
